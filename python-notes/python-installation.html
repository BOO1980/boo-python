Overview

  • The easiest way to install Python on Windows and Mac is to download the installer from the official Python website.
  • Go to https://www.python.org/downloads/ to download the installer. And hover over downloads.
  • The installation can be verified by opening up a command line like PowerShell and running python --version to check the installed version.

This command will display the version of Python that is currently installed on your system.
